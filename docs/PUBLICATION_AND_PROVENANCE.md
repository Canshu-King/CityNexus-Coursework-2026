# Public release provenance and privacy

## Origin
Main code source: private CityNexus branch `coursework/part2-20261104-kickoff`, commit `9115b6521678d587c2dea1cee0b20b08413854a0` (2026-11-04).

Experimental code source: separate private branch `gpt/revolution-r33-open-world-journey-adaptation`, commit `a5a2f1096e0fbd806acd8be134fe8fb6095ad1a9` (2026-10-11).

Curated for teacher review: 2026-11-06.

## Included
Main application source, tests, formal modeling, 138 candidate requirements and traceability, selected editable diagrams and PDF previews, and isolated experimental source.

## Not included
Original Git history, raw local databases, deployed provider secrets, `.env` runtime values, personal workstation folders, extensive review/archive snapshots, and official Moodle submission files that cannot be verified in this release.

## Why a fresh public repository matters
**Do not change visibility of the original private CityNexus repository.** That would expose its full history and other branches, including past artifacts that have not been audited.

Publish this *curated* snapshot as a new repository with a **fresh orphan root commit** (no private parents), after reviewing credentials, personal information, licenses, binary document metadata and generated artifacts. A secret scan is a useful check but cannot guarantee safety.

## Status
The public-release branch is a staging candidate. It is **not certified** to be clean of secrets or personal data until reviewed, and its exported code was not freshly tested.
